TRAINING PROGRAM

這堂跑班會帶你練什麼？

不只是帶你繞圈跑步！我們從「預防運動傷害」與「跑姿基本功」出發，讓你跑得更遠、更輕鬆。

🏃🏻‍♂️

跑姿分析與調整

透過動作觀察與分解練習，幫你調整落地步態、擺臂與身體前傾角度，改善容易費力或傷膝蓋的跑法。

🔥

科學化跑前熱身

帶你做完整的動態伸展、關節啟動與馬克操，讓肌肉與心肺進入最佳狀態，大幅降低拉傷風險。

💪

專項肌力與核心強化

針對跑者最需要的核心穩定、臀腿推蹬與足踝力量進行訓練，讓你在比賽後半段依然維持穩定步頻。

💆🏻‍♂️

跑後緩和與運動防護

重視每次訓練後的收操伸展與運動防護觀念，教你在日常練跑中照顧身體，真正做到無傷長跑。

📌 三階段分級訓練（初學者到進階跑者皆可參加）

依每位學員目前的體能與目標彈性調整強度，不用擔心跟不上！

初階班 🏃🏻‍♂️

養成習慣・無傷起跑

適合剛接觸跑步的新手、想運動流汗、或是跑沒多久就容易喘與腳痛的朋友。

  • ✓ 建立正確呼吸節奏與輕鬆跑姿
  • ✓ 完整跑前動態熱身與跑後收操
  • ✓ 基礎肌群喚醒，邊跑邊聊無壓力
進階班 🏃💨

跑姿優化・耐力升級

適合已經有慢跑習慣、想提升配速穩定度，或準備參加 10K／半馬賽事的跑友。

  • ✓ 個人化跑姿微調與步頻提升訓練
  • ✓ 有氧耐力、節奏跑與配速控制練習
  • ✓ 跑者專項肌力強化，預防長距離疲勞
突破自我 💪

強化課表・挑戰個人 PB

適合渴望在 5K、10K、半馬或全馬突破卡關、刷新個人最佳紀錄的進階跑者。

  • ✓ 台灣半馬百傑教練親帶間歇與速度課表
  • ✓ 實戰配速策略與賽前調整經驗分享
  • ✓ 隊友互相破風配速，激發最強潛能
